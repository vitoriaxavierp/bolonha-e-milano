# Bolonha e Milano

Projeto de desenvolvimento do jogo Bolonha e Milano, um jogo de estratégia econômica medieval desenvolvido em Java.

## Tecnologias utilizadas

- Java 17

## Estrutura do projeto

- `src/bolonhaemilano/`: contém os arquivos do código-fonte Java.
- `uml/`: contém os diagramas de classes do projeto.
- `casos-de-uso/`: contém os diagramas de casos de uso.

## Como compilar e executar

A partir da pasta principal do projeto, execute:

```bash
javac -encoding UTF-8 -d bin src/bolonhaemilano/*.java
java -cp bin bolonhaemilano.Main
```
